# Real-Time Character Counter

## 📌 Project Description

The Real-Time Character Counter is a simple web application built using HTML, CSS, and JavaScript. It allows users to type a message into a text area while displaying the number of characters entered and the number of characters remaining.

The application has a maximum character limit of 200 characters and displays a warning message when the limit is reached.

## ✨ Features

- Text area for entering messages.
- Maximum character limit of 200 characters.
- Real-time character counting.
- Displays the number of characters typed.
- Displays the remaining character count.
- Warning message when the character limit is reached.
- Prevents users from exceeding the character limit.
- Responsive and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Real-time character counting and validation.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Type a message into the text area.
5. Observe the character count and remaining characters update automatically.

## ⚙️ How It Works

1. The user enters text in the textarea.
2. JavaScript listens for the `input` event.
3. The application calculates the number of characters entered.
4. The remaining character count is updated based on the 200-character limit.
5. A warning message appears when the limit is reached.
6. The HTML `maxlength` attribute prevents the user from entering more than 200 characters.
